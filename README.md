# PathwayVis: Interactive Visualization of Decision Pathways in a Tree-Based Machine Learning Model
PathwayVis Demo Version.

## Author
Yuanzhe Jin

## Overview
Decision trees are among the most widely used machine learning models, valued for their interpretability and computational efficiency. However, existing visualization approaches typically present static representations, making it difficult to trace the decision paths of individual samples within the tree. In this paper, we introduce an interactive visualization tool called “PathwayVis” that enables users to explore decision paths in trees generated by the scikit-learn library. Through case studies on public datasets, we demonstrate the tool’s effectiveness and discuss how it can support tasks such as model debugging and transparent communication of machine learning decisions. This work contributes to the growing field of interactive visual analytics for interpretable machine learning.
